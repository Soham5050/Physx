# Changelog

## Cinematic Edition

- Reworked the earlier 3D prototype into a procedural OpenGL 3.3+ application.
- Preserved the Schwarzschild and Ellis-Bronnikov null-geodesic models, RK4 integration, and spatial embedding equations in a separate physics module.
- Added a procedural nebula/starfield background, shaded embedding surfaces, illustrative accretion-disk animation, horizon/photon/throat guides, geodesic markers, bloom, tone mapping, and an on-screen scientific HUD.
- Added Exploration and Laboratory interface modes, camera panning, zoom/orbit, model focus, keyboard parameter controls, and adaptive internal resolution scaling.
- Added standalone numerical sanity checks and a Windows setup/launch script.
